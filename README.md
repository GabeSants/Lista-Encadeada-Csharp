# Lista Encadeada C# - LinkedList Example

Este repositório contém uma implementação simples de uma lista encadeada em C#, com operações básicas como adicionar, remover e exibir elementos.

## Funcionalidades

- **Adicionar**: Insere elementos no final da lista encadeada.
- **Remover**: Remove um nó com base no valor fornecido.
- **Exibir**: Exibe todos os elementos da lista encadeada.

## Como rodar

### Pré-requisitos

- [.NET SDK](https://dotnet.microsoft.com/download) (recomenda-se a versão mais recente do .NET 6 ou superior).

### Passos

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/Lista-Encadeada-Csharp.git
    ```

2. Navegue até o diretório do projeto:
    ```bash
    cd Lista-Encadeada-Csharp
    ```

3. Execute o projeto:
    ```bash
    dotnet run
    ```
